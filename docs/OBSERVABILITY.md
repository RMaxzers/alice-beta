# Observability

**Prometheus stores the series; Grafana shows them; Alice queries the sources and explains them.**

## Sources (all verified with real data)
| Layer | Source | Series (real names) |
|---|---|---|
| Windows host | windows_exporter 0.31.8 (cpu, memory, logical_disk, physical_disk, net, os, system) | `windows_cpu_time_total`, `windows_memory_available_bytes`, `windows_memory_physical_total_bytes`, `windows_logical_disk_free_bytes`, `windows_net_bytes_total`, `windows_system_boot_time_timestamp` |
| GPU | Alice sampler → `nvidia-smi --query-gpu` every 15 s | `alice_gpu_utilization_percent`, `alice_gpu_memory_used_bytes`, `alice_gpu_memory_total_bytes`, `alice_gpu_temperature_celsius`, `alice_gpu_power_watts`, `alice_gpu_sample_success` |
| Ollama | Alice sampler → `/api/tags`, `/api/ps` | `alice_ollama_models_installed`, `alice_ollama_model_loaded_vram_bytes{model}` |
| Alice | direct instrumentation (port 9101) | `alice_requests_total{route,provider,model_alias,status}`, `alice_request_duration_seconds`, `alice_queue_wait_seconds`, `alice_provider_request_duration_seconds{provider}`, `alice_provider_attempts_total`, `alice_rag_retrieval_duration_seconds`, `alice_routing_duration_seconds{decided_by}`, `alice_provider_tokens_total`, `alice_provider_cost_usd_total`, `alice_egress_blocked_total{reason}`, `alice_queue_depth`, `alice_dependency_up{dependency}`, `alice_errors_total{component}` |
| Dependencies | health checks every 30 s | `alice_dependency_up`, plus Prometheus `up` for scrapes of alice, windows, prometheus, qdrant, grafana |
| Containers | DockerAdapter (read-only broker) | Docker is **not installed** in Beta 0.1 (D1) → reported as unavailable; no container series |

Windows host metrics are the real host (not a VM). GPU metrics disappear while Alice is stopped (limitation of sampling from Alice).
User requests vs provider attempts are separate counters (retries don't inflate requests).

## Alice answering about itself
`OBSERVABILITY` questions are answered **without an LLM** by `services/observability/answers.py` from a reviewed PromQL
catalog (`services/observability/prometheus.py`), nvidia-smi, the Ollama API, health checks, the request log and the ledger.
Each answer states source, window, sample age and gaps; missing data is reported as missing (never 0); time correlation
is never presented as causality. Range queries are clamped to 24 h, ≤ 100 series, ≤ 10 000 samples.

Supported questions include: ¿Cómo está Alice? · CPU/RAM · VRAM · ¿Qué modelo está cargado? · consultas locales/cloud hoy ·
coste hoy · consulta más lenta · GPU en los últimos N minutos · ¿por qué estuvo lenta la última hora? · ¿qué pasó en mi última
consulta? · contenedores / logs de contenedor (reports Docker unavailable).

## Grafana
Dashboard **ALICE / OVERVIEW** (`infra/grafana/dashboards/alice-overview.json`, generated by `infra/grafana/build_dashboard.py`),
provisioned read-only with datasource uid `alice-prometheus`. 31 panels: status, host CPU/RAM/net/disk, GPU util/VRAM/temp/power,
request rate by route, route distribution, local vs external, p50/p95 latency (from histograms), stage p95 (queue/RAG/provider),
errors and egress blocks, tokens, scrapes. Every query was executed against Prometheus; three panels (cost, errors, egress blocks)
show "sin datos" until such events occur — that is correct, not zero.

Access: local http://127.0.0.1:3000 (admin, password in `.env`), tailnet https://eva01.tail3f8e85.ts.net:8444 (user `viewer`,
role Viewer). Anonymous access disabled; analytics/update checks disabled.

External Grafana: `services/integrations/grafana_external.py` (`GRAFANA_EXTERNAL_ENABLED=false` by default, read-only paths only).

## Logs
Alice writes JSON lines to `logs/alice.jsonl` (rotated 5 × 5 MB) with level, timestamp, component, opaque request id and
duration — never prompts, documents or answers. Loki/Alloy were not deployed (optional; see ROADMAP).
