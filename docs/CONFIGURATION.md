Other configuration (versioned):
- `config/models/aliases.yaml` — model aliases and route → alias mapping.
- `config/routing/rules.yaml` — deterministic routing rules (ordered).
- `config/routing/exemplars.yaml` — semantic-routing tuning set (must not overlap `tests/routing/cases.yaml`, enforced by a test).
- `infra/prometheus/prometheus.yml` — scrape targets (15 s).
- `infra/grafana/provisioning/**` — datasource + dashboard provider.

Runtime toggle: **Solo local** (Settings screen or `PUT /api/settings {"local_only": true}`) — resets to `ALICE_LOCAL_ONLY` on restart.

Integration states used across the UI/API: `DISABLED`, `READY_FOR_CONFIGURATION`, `not_configured`, `configured_not_tested`, `healthy`, `degraded`, `unavailable`.
